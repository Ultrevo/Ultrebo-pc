# Security

If you find a security problem in Ultrebo, please report it privately instead of posting details publicly:

- Use **Security > Report a vulnerability** on this repository (GitHub private reporting), or
- Message Ultrevo in the [Discord server](https://discord.gg/mAKGfaAWWW) and ask for a private channel.

Please include what you found, how to reproduce it, and your operating system and version.
